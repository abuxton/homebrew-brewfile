# homebrew-brewfile

A personal [Homebrew Bundle](https://github.com/Homebrew/homebrew-bundle) configuration used with [Strap](https://github.com/MikeMcQuaid/strap) to bootstrap a macOS development environment.
You don't have to use strap, you can simply clone the repo, install Homebrew, and run `brew bundle install` manually.

## Overview

This repository contains:
- **Brewfile** – Homebrew package manager definitions (taps, formulae, casks, and Mac App Store apps)
- **Gemfile** – Ruby gem dependencies for command-line tools and development utilities
- **.ruby-lsp/Gemfile** – Ruby LSP development dependencies (auto-generated and git-ignored)

## Getting Started

[Strap](https://github.com/MikeMcQuaid/strap) automatically clones this repository and runs the macOS bootstrap process. After Strap completes, follow these steps in order to finish setting up your development environment:

### Step 1: Install Homebrew Packages

This first depends on `Brew Bundle` (https://docs.brew.sh/Manpage#bundle-subcommand), which allows you to define and install Homebrew packages from a `Brewfile`. Make sure you have Homebrew installed before running this command.

```bash
cd /Users/abuxton/homebrew-brewfile
brew bundle install
```

This installs all Homebrew package Types defined in the `Brewfile`, including:
- **Taps** – Third-party Homebrew repositories (including private ones via SSH)
- **Formulae** – Command-line tools and libraries (including `rbenv`)
- **Casks** – macOS GUI applications
- **Mac App Store apps** – Applications installed via the Mac App Store
- **npm** – Node.js package manager
- **vscode** – Visual Studio Code editor

> Note: If you add new packages to the `Brewfile`, you should run `brew bundle install` again to ensure they are installed.
> For the full list of types, see [Brewfile types](https://docs.brew.sh/Brew-Bundle-and-Brewfile#types).

### Step 2: Set up Ruby Environment

This uses `rbenv` (installed via `brew bundle`) to install the correct Ruby version (3.3.7) and installs Bundler, which manages Ruby gem dependencies.

### Step 3: Install Ruby Gems

```bash
cd /Users/abuxton/homebrew-brewfile
rbenv install 3.3.7
rbenv local 3.3.7
gem install bundler
bundle install
```

This installs all gems specified in the `Gemfile` for your global Ruby environment. These gems provide command-line tools and utilities such as:
- `colorls` – Colored directory listings
- `rubocop` – Ruby style checker and formatter
- `solargraph` – Ruby language server for IDE integration
- `yard` – Ruby documentation generator
- `github-pages` – Jekyll and related gems for GitHub Pages
- And more (see `Gemfile` for complete list)

## Maintaining the Brewfile

> The Brewfile should be kept up-to-date with the packages installed on your system. Whenever you add or remove packages, make sure to update the Brewfile accordingly.
> Brew file now has the concept of [Trust](https://docs.brew.sh/Tap-Trust#trusting-in-a-brewfile) applied to the taps defined within it. This ensures that only trusted taps are used when installing packages from the Brewfile.

### Adding New Homebrew Packages

1. **Install the package manually:**
   ```bash
   brew install <formula>
   brew install --cask <cask>
   mas install <app-id>
   ```

2. **Update the Brewfile** (preserves package descriptions and existing structure):
   ```bash
   brew bundle dump --describe --force
   ```

3. **Review and commit** the changes to `Brewfile`

### Brewfile Structure

The `Brewfile` is organized as follows:

1. **`tap`** entries – Third-party Homebrew tap registrations (alphabetically sorted)
   - Private taps use SSH URLs: `tap "org/name", "git@github.com:org/repo.git"`
   - Public taps use standard HTTPS URLs
2. **`brew`** entries – Command-line formulae
   - Each entry includes a description comment generated by `brew bundle dump`
   - Some formulae use special options like `link: false` or `link: true` (do not remove these)
3. **`cask`** entries – macOS GUI applications
   - Casks from specific taps use the namespaced form: `cask "tap/formula"`
4. **`mas`** entries – Mac App Store applications
   - Specified with numeric App Store ID: `mas "App Name", id: 123456789`

### Keeping Brewfile in Sync

To check what's installed versus what's defined in the Brewfile:

```bash
brew bundle check
```

To remove packages not listed in the Brewfile:

```bash
brew bundle cleanup --force
```

## Maintaining the Gemfiles

### Adding New Ruby Gems

1. **Add the gem to `Gemfile`** in the root directory (this is for your global Ruby environment):
   ```ruby
   gem "gem-name", "version"
   ```

2. **Install the new gem:**
   ```bash
   bundle install
   ```

3. **Commit both `Gemfile` and `Gemfile.lock`** to version control

### Gemfile Structure

- **Gemfile** – Specifies the Ruby version and gem dependencies
  - Specifies `ruby "3.3.7"` to match the development environment
  - Includes gems used as command-line tools and utilities
  - Comments indicate the purpose and usage of each gem

- **Gemfile.lock** – Generated automatically by Bundler
  - Locks gem versions for reproducible installations
  - Should be committed to version control
  - Do not edit manually; Bundler updates it when you run `bundle install` or `bundle update`

### Ruby LSP Gems

The `.ruby-lsp/Gemfile` is automatically generated by the Ruby LSP VS Code extension and is git-ignored. It includes:
- The main `Gemfile` dependencies (via `eval_gemfile`)
- The `ruby-lsp` gem itself for development

Do not manually edit this file; it will be regenerated automatically.

### Updating Gem Versions

To update all gems to their latest compatible versions:

```bash
bundle update
```

To update a specific gem:

```bash
bundle update gem-name
```

Then review and commit changes to `Gemfile.lock`.

## Workflow Summary

1. **Initial setup:** Run Strap, then follow the "Initial Setup with Strap" section above
2. **Regular use:** Packages are already installed; just use them
3. **Adding packages:** Install manually, run `brew bundle dump --describe --force`, review, and commit
4. **Adding gems:** Edit `Gemfile`, run `bundle install`, and commit both `Gemfile` and `Gemfile.lock`
5. **Synchronizing:** Run `brew bundle check` and `bundle install` periodically to ensure everything matches
